# Central de materiais

Aplicativo Flutter para cadastrar, editar, excluir e acompanhar materiais armazenados localmente.

## Personalizações desta versão

- Filtro da lista por nome ou categoria.
- Indicação visual do estado do estoque.
- Ajustes de tema e espaçamento dos cards.

**Adaptação:** João Pedro Cardoso. Esta pasta contém personalizações sobre o código-base recebido; mantenha os créditos do material original conforme a orientação da atividade.

## Como executar

Com Flutter e Google Chrome instalados, rode `flutter pub get` e depois `flutter run -d chrome --web-port=8080`.
